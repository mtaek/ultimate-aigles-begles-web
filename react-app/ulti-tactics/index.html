Terrain

Demi-terrain vertical · attaque vers l’en-but en haut.

Comment faire
  1. Glissez les joueurs depuis le banc sur le terrain (ou cliquez-les). Glissez-en un sur le banc pour le retirer.
  2. Glissez le disque sur le porteur.
  3. Cliquez + Temps, puis déplacez les joueurs : la course se dessine toute seule.
  4. Pour une passe, glissez le disque sur le receveur. Le rond orange courbe une course ou une passe.
  5. Cliquez ▶ pour animer, ou ◀ ▶| pour avancer temps par temps.

Joueur

Le numéro reste sur le joueur ; son nom apparaît en dessous sur le terrain et dans les exports.

Zones pédagogiques

Lanceur droitier. La zone blanche « OUVERT » montre où le lanceur peut jouer, la barre orange le côté fermé par le marqueur.

Choisissez une forme puis tracez-la sur le terrain. Elle appartient au temps affiché.

Orientation du défenseur

0° = regarde vers l’en-but attaqué, sens horaire. Vous pouvez aussi tourner le défenseur avec la poignée bleue sur le terrain.
