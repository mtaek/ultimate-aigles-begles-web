# Quiz Ultimate Frisbee - Les Aigles de Bègles

Quiz interactif pour tester vos connaissances sur l'Ultimate Frisbee.

## 📝 Description

Ce quiz propose 10 questions aléatoires parmi une base de 20 questions sur :
- Les règles de l'Ultimate Frisbee
- Les techniques et tactiques
- Le vocabulaire spécifique
- La culture du sport

## 🎯 Fonctionnalités

- 10 questions aléatoires par session
- Choix multiples (4 réponses possibles)
- Explications détaillées après chaque réponse
- Score final avec message personnalisé
- Possibilité de rejouer à volonté

## 📊 Contenu éducatif

Le quiz couvre les thèmes suivants :
- Composition d'une équipe
- Dimensions du terrain
- Règles de déplacement
- Spirit of the Game
- Comptage (stall count)
- Zones et stratégies
- Brick et engagements
- Durée des matchs
